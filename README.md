# Simple Personal Website

This is a minimalist personal website made using NextJS and Tailwind CSS. It serves as a digital portfolio to showcase projects, skills, and professional information.

## Features

- Responsive and clean design
- Project and skills showcase
- Easy to customize and deploy

## Tech Stack

- NextJS using Javascript
- Tailwind CSS

## Getting Started

Clone the repository and run locally:

```bash
git clone https://github.com/hanifas-cs50/portfolio
cd personal
npm install
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) in your browser.
